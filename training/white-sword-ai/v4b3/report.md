# 白劍 AI v4-B.3 受約束的策略更新

這一輪要分清的是：單步方盒裡還有沒有一組權重，能學會 v2 還沒選到的偏好，同時保住其他局面的實際選牌。搜尋範圍是 Hard cap 7、單步 1.5、權重 −6～6，雜湊桶維持凍結。正式權重仍是 v2，沒有採用任何更新，也沒有改 Hard Search 2。

## 結論
有 1 個偏好，沿特徵差的射線會改到別的局面，但方盒裡存在另一組權重，121 個已檢查局面裡只有目標本身換了選牌。這部分是更新演算法的問題，特徵還表達得了。
有 2 個偏好找得到權重，但每一個都有一個局面用到同一張卡的特徵，單步方盒裡任何能改選目標的權重都會連它一起改。射線上其他不相關的改動則可以避開。
有 3 個偏好在整個單步方盒裡都沒有解，雜湊桶放開之後仍然沒有。現有特徵加上單步 1.5 到不了這些對比。
權重沒有寫進模型。名義上區間排除 0 的比較，多數只靠 8 或 16 次，而且會在看起來顯著時停止抽樣。42 次比較裡，Benjamini-Hochberg 只留下 1 個 v2 本來就選對的阻擋。
新種子固定再抽 16 次。3 個方盒學得會的原偏好裡，原方向再次排除 0 的有 0 個，方向反過來且排除 0 的有 1 個（a925bcd5 偏向 BLC-4-070）。連帶局面 2 個，其中新區間含 0 的有 2 個。

- 每個約束都要求目標動作的分數高過帶內每一個其他動作。只保住兩個被點名動作的順序、讓第三個動作變成首選，算沒有通過
