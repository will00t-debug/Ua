# 白劍 AI v4-A

v4-A 用演化搜尋訓練固定 50 張的 BLEACH 白劍牌組。每一輪自動產生 8 個候選、對戰、淘汰，並只用新種子做一次冠軍挑戰。沒有人指定哪一步該出哪張牌。

正式版 v2 權重、通用 V2 引擎、Hard Search 2、對戰選單和正式部署都不會被這套流程修改。通過門檻的模型只寫進實驗冠軍。

## 執行

```bash
node scripts/white-sword-v4a.mjs smoke
node scripts/white-sword-v4a.mjs round
```

`round` 會從已完成的輪次接下一輪。中斷時再執行一次會跳過已經寫入的對局。若上一輪因為非法行動或無法重現而停止，程式不會自動開新輪。

GitHub Actions 工作流程是 `.github/workflows/white-sword-v4-evolution.yml`，只接受手動啟動。定時排程必須放在預設分支才會生效，所以這次不加排程。

## 對局與門檻

完整一輪在全數候選都合法時是初選 192 場、複選 288 場、獨立驗證 720 場配對加 120 場鏡像。初選和複選只決定誰進入驗證。

實驗冠軍要同時滿足：配對勝率差至少 +5 個百分點、該差的 95% 種子集群信賴區間下限大於 0、120 場鏡像勝率至少 55% 且 Wilson 下限高於 50%、三個基準牌組的勝率差都不低於 -3 個百分點，而且非法、洩漏、fallback、逾時、死循環和未完成對局都是 0。

## 種子

第 r 輪使用 `100000 + (r-1)*1000` 這個區塊。探測、初選、複選、配對驗證和鏡像驗證各用不同種子。`94000–94016` 與 `130000–130016` 永久不用。舊實驗用過的種子列在 `training/white-sword-ai/v4a/lib/protocol.mjs`。

## 下一輪

實驗冠軍和種子帳會留在 `training/white-sword-ai/v4a/`。下一輪直接執行 `node scripts/white-sword-v4a.mjs round`，不需要手移權重。若連續多輪幾乎沒有出牌分歧，探索強度會乘上 1.25，單項權重變化仍不超過 1.5，晉級門檻不變。

強化學習模型可以之後用 `registerProposer` 接上。目前這個位置沒有神經網路。
