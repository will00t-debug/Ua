# 白劍 v3.3 — 下一回合戰術壓力（獨立實驗）
不自動合併、不自動上線、不碰正式 v2。這是評分器與訓練資料品質的實驗，不是完整的蒙地卡羅樹搜尋。

## 與 v3.2 的差異
v3.2 讓線性 policy 學習 Hard 48-node root 的短期 Q 候選排序，且只在非 pending 主階段／攻擊階段套用。840 場中 v3.2 234/360、v2 233/360，直接鏡像 60/120，不足以證明有進步。

v3.3 保留合法性、模型切換與 48 nodes Hard root cap 7，改良 **offline 訓練標籤**：
- 經 Hard 搜尋實測、且位於 cap 7 之內的動作，額外在 Hard **已經遮蔽隱藏資訊的虛擬狀態**上，各自模擬眼前一個合法動作。
- 按照己方與對手的公開場上角色，預測下一次準備階段後可能形成的攻擊能力、BP 對位與反擊；己方已知手牌可搭配的 Raid 只提供有限加分。
- 無法知道對手手牌或尚未翻出的 LIFE 觸發，因此預測器**不**使用實際牌庫順序／血區卡 ID、不進行完整對手回合模擬；只輸出 [-14,+14] 的相對壓力改變，不輸出虛擬卡資料。
- offline 訓練候選評分 = 短期 Hard Q + 0.6 × 下一回合壓力改變，挑選分差 1.5–7 的偏好標籤。絕不拿這個預測分數直接取代 Hard 的合法動作／安全上下限；正式行動一律仍由 Hard+model cap 7 決定。
- v3.3 模型只在主階段／攻擊階段且無 pending 使用。其餘強制決策沿用 v2 模型。
