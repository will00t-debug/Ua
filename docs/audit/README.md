## 本批共用修正

### BP 0 以下依規則退場

Q94（https://www.unionarena-tcg.com/jp/faq/list.php?number=94）：卡牌效果使場上角色 BP 變成 0 以下時退場。Q187：阻擋時效果先處理完，BP 0 的角色才退場，之後不進行戰鬥。Q1139（2024-10-18）：這次退場不是「キャラの効果による退場」，所以 KMR-1-025 的代替退場與 KMR-1-051 的對手效果支付都不能用。Q1898／Q1899（2026-01-09，https://www.unionarena-tcg.com/jp/faq/list.php?freeword=BP%E3%81%8C0）：效果處理途中 BP 一度變成 0，只要該效果結束時 BP 已不是 0，就不退場。

dist/universal-v2/engine.mjs openBpZeroRetirements、continueEffectQueue、retireBatchOne、effect-target。dist/universal-v2/csm-runtime.mjs debuffFront 只記 BP，不在句子中途退場。

前線與能源線的角色。同一印刷效果的後續工作與待處理選擇共用 effectScope，中途不檢查。下一個不同效果開始前，以及佇列清空時，才檢查。選擇結束且 BP 仍為 0 以下才由規則退場。同時到 0 的角色各退一次。IYS-1-028 的離場代替仍會問。場地卡不退。kmrAnchored 仍留在場上。鍊鋸人 debuffFront 的呼叫者都等效果結束。

tests/v2-bp-zero-retire.test.mjs 用 buffSelf 先減 10000、中間經過 CSM-1-016 的選擇、再加回 10000。不同 effectScope 會在下一個效果前退場。tests/v2-csm-001-010.test.mjs 的 Q1898；tests/v2-csm-faq.test.mjs 的 CSM-1-017 BP 0

### 被阻擋時是攻擊角色的效果

KMR-2-054 印刷文本「このキャラがブロックされた時」指自己的攻擊被阻擋。記憶體切換登場時可以改成抽最多 1 張，包含 0 張。卡頁沒有另立 FAQ。

dist/universal-v2/engine.mjs 阻擋成立時把 kmr2 blocked 排給攻擊者，並在選擇後用 kmr2ResumeBattle 結算戰鬥。dist/universal-v2/kmr2-runtime.mjs blocked054、mayDraw。

KMR-2-033、039、048、054、079 的被阻擋效果都從攻擊開始實測：被阻擋才發動，沒被阻擋不發動，防守方不會借用攻擊方的效果，選擇後戰鬥只結算一次。039 沒有突襲狀態時不發動；三張卡名不含メテオ的天ノ川學園高校才棄牌，之後活動並獲得傷害 2。048 要先由登場時的記憶體切換支付取得該能力。079 需要突襲狀態，以及其他兩張イマジン或卡名含電王的角色。033、039、048、079 的其他句子沒有全部走完，維持部分核對或未檢查。

### 鍊鋸人退場原因與登場看牌順序

CSM-1-006 只有「自分の效果で退場」才可改看 4 張。Q1139：BP 0 規則退場不是角色效果。CSM-1-008 的印刷順序是看 3 張、排列其餘、再把手牌放場外，然後才處理真紀真或蕾潔。Q2074：加入的角色不限真紀真或蕾潔。

dist/universal-v2/engine.mjs normalizeRetireCause、retire、queueRetirement。暫停的 leave-replacement、effect-substitute-retire、raid-leave、field-leave-remove 與 csm 離場代替都帶著 retireCause。dist/universal-v2/csm-runtime.mjs retireUid、retireThen、runRetire。原因未填不再當成自己的效果。

鍊鋸人退場都會帶 by、controller、sourceUid。CSM-1-006 只有 by 為 own、控制者是自己、而且有來源 UID 才能改看 4 張。040、077 讓對手的 006 退場只抽 1 張。016 讓自己的 006 退場仍可看 4 張，而且看完才做後續的活動、BP 與衝擊。離場代替暫停後，接受代替或放棄都留著原因。
