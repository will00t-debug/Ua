# 驅魔少年 UA58BT 共通引擎登錄

日文產品是補充包 `UA58BT`（系列 `570158`），2026-11-27 發售。官方繁中系列選單停在 `UA57BT`，沒有這套的官方繁中卡頁。牌組編輯器的作品名是「驅魔少年」。`name` 與 `effect` 用 Rugia 港譯；Rugia 沒有該頁時，這兩個欄位保留日文官方印刷。`effectJa` 一律是日文官方印刷，引擎只對這段文字。港譯不是官方繁中。

可組身份 80 張：`DGM-1-001` 到 `DGM-1-080`。SR 12、R 12、U 28、C 28。藍 40、紫 40。角色 66、場地 2、事件 12。AP 卡不組進牌組。平行卡與 Rugia 上的 `UAPR/DGM-1-` 是同一身份的另一個印刷，不是新編號。`DGM-1-009` 同時記著 `UA58BT/DGM-1-009_p1`、`_p2` 與兩張 `UAPR` 圖。

## 能量、BP、特徵

發生能量讀 `発生エナジー` 的 alt 色點。尾端 `+` 是 `genMark`，不加進 `gen`。檔名 `ico_resource_energy_*N.png` 的數字是圖檔編號。`DGM-1-017` 的 alt 是兩點藍，`gen` 是 2，檔名編號是 3。必要能量的 `色-` 是 0，顏色字元留著，第 1 回合可以從手牌打出。`DGM-1-023`、`DGM-1-025` 的必要能量是 0。`BP+` 的整數是基礎 BP，加號是設計記號。斜線特徵是一個印刷詞，這套目前沒有斜線特徵，也沒有 `traitComponents`。

## 這次沿用的 267 筆閘門

- 看過的視窗包含不能選的卡，沒選的維持非公開。
- 突襲框內的字只在蓋上的突襲上結算。9 張的框內關鍵字已進 `raid-box.mjs`，框外的句子不在清單裡。
- 發生能量讀色點。檔名編號與尾端 `+` 不改 `gen`。
- 必要能量 0 就是 0，第 1 回合可以打出。
- 從手牌打出的角色記下 `entryTurn`，落點是共用的場上格子。
- 作品沒有自己的 opcode，也沒有加進 `V2_TITLE_IDS` 或舊的對戰 runtime。
- 沒有官方標誌圖檔，牌組磚用目錄卡圖，不另做標誌。
