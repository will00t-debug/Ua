# V2 決策學習

這個程式讀取已經上傳的玩家決策，做出權重，供單人對戰的「學習」難度使用。

收集紀錄本身不會讓電腦變強。按下「用這些紀錄學習」之後，才會產生候選模型。模型提出和你相同的選擇，也不等於勝率或戰力已經提高。

目前的模型格式是 `ua-v2-learn-v4`。`ua-v2-learn-v1`、`ua-v2-learn-v2` 和 `ua-v2-learn-v3` 用的是舊特徵，不能直接套用。對戰會沿用困難 AI，並提示重新訓練。舊權重和玩家紀錄留在帳號裡。驗證沒過時，不會替換目前啟用的模型。沒有可用模型、候選未啟用、舊格式或讀取失敗時，單人對戰仍會開局，畫面寫明本場使用困難 AI 和原因。只有載入目前格式的模型才使用學習模式。

## 學習用哪些列

- `source` 與 `actor` 都是 `human`。
- 當時有兩個以上合法選項。只有一個合法選項的步驟會略過。
- AI 操作、對局結果列、含對手隱藏手牌、牌序、未公開生命、種子或勝敗的列都會略過。
- 勝敗不會進特徵。
- 賽後示範若有修正，會和該場原本的決策留在同一邊。沒有示範也可以學習。

特徵是「當時看得到的場面」配上「這一筆合法操作」。生命、AP、能源、空位和阻擋人數會跟著攻擊、阻擋、放行、登場、突襲、移動或結束階段一起編碼。同一局面裡每個候選都一樣的數字，不會再單獨加分。

卡牌 UID 只用來找到這一手看得到的牌。跨對局學的是卡牌屬性、位置、目標和突襲底座。卡池和正式 V2 對戰使用同一份 `officialV2Pack`，包含目前可進入對戰的作品與彈別。費用、AP、印刷 BP、產能和突襲都取自這份卡池。卡池沒有的卡保持未知，不會用 0 冒充。

操作特徵除了類型、方式、UID、行列和格位，還包含會改變意義的白名單：數值、去向、已知放置位置、公開分支，以及棄牌、回復、休息的可見牌。牌頂放回或送場外時，會加上這一效果剛揭示、而且行動玩家已經可以看的那張牌和它的公開印刷屬性。更早的揭示、其他未知牌和原始 UID 不會進這一手的特徵。排序用的 key 會先拿掉 UID 和很長的對局內編號。完整操作 JSON、原始 UID、畫面標籤和隱藏牌序都不是特徵。

## 怎麼驗證

三件事分開記：

- 分割有效：至少留出一整場，沒有把同一場切成訓練和驗證，訓練側仍有足夠決策。
- 評估資料足夠：留出至少 2 場，而且至少 8 筆實戰會評分的決策。調度和排序不算。留出 1 筆不算。全部都是調度時，即使整體吻合率是 100%，也不能啟用。
- 允許啟用：評估資料足夠，而且可介入決策的模仿相同比例至少 50%。回退算進分母。整體吻合率、可介入筆數和實戰改選率分開記。沒有引擎分數時，改選率是空的，不假裝已經量過。只看得到決策類型、還沒有引擎分數的步驟標成可能介入；有引擎分數才算已確認可介入。這是模仿比例，不是勝率。

可以公平比較時，候選和目前模型用同一批雙方都沒看過的留出對局。資料不夠、格式不同或對局重疊時，會標明沒有比較，不會假裝比過。目前模型比較好時，不啟用候選。

資料不足可以保存候選模型，但不會默默換掉目前啟用的模型。沒有通過驗證時，對戰沿用目前可用模型或困難 AI。

教 AI 頁可以按「恢復上一版」。恢復只影響這個帳號的啟用模型，舊權重和玩家紀錄都留著。

合法操作超過 64 個時，負例用可重現的抽樣，不依按鈕順序取前幾個。

## 對戰時怎麼用

單人對戰把難度選成「學習」後，困難 AI 先評分。學習加分以困難 AI 的原選擇為基準。加分是 `min(上限, 倍率 × max(0, 偏好差 − 門檻))`。倍率是 4，門檻沿用 0.2，不再除以這一手最大的偏好差。偏好差 0.21 的加分是 0.04。超過門檻越多，加分越大，最後停在既有上限。零加分維持困難 AI 的原走法。兩個走法的原始分數相同時，通過熟悉度與安全檢查、而且加分大於 0 的偏好可以打破平手。原始分數不同時，仍要跨過困難 AI 原本的門檻：沒有待處理、阻擋和生命相關的寬搜尋是 7 分，效果選擇是 0 分。計入加分之前，另有獨立的原始分差上限，目前是 0。替代走法的困難 AI 原始分數只要比原走法低，就維持困難走法，即使學習加分足以補回也一樣。只有原始分數相同，或替代走法的原始分數沒有更低時，加分才可能改選。這個 0 是用沒有參與訓練、也沒有拿來做正式對照的種子 31、32 比較後留下的：只在同分介入是 12/24，允許 0.5 分差是 11/24。正式對照的種子 21、22 沒有拿來選這個數字。只有加分真正促成的改選才算進學習影響率。每一個可能被學習改選的候選，都要自己通過樣本、熟悉度和安全檢查。最終選到的操作會再查一次，不能沿用別的操作的通過結果。困難 AI 原來的選擇一直留在候選裡，就算它沒有學習資料也不會被拿掉。沒看過的卡不能靠學習加分，也不能靠壓低別人的分數勝出。

立即斬殺、會立刻輸掉的操作、可見資訊下可證實的必要阻擋，以及能源很低時的補能源，仍沿用困難 AI。分數差不夠、樣本不足、沒看過的情境、舊模型或壞掉的模型，都回退困難 AI。回傳的操作必須是當下的合法操作。既有的階段步數上限仍然在。

診斷可以分出困難 AI 原選擇、學習偏好、最終選擇、有沒有真的改走法，以及最終操作的回退或保護原因。診斷不寫進每一步的正式日誌。

權重留在帳號資料庫。不要把玩家匯出的 JSONL 或含真實對局的權重檔提交到 Git。

本機可以用：

```bash
node scripts/v2-decision-learn.mjs 匯出的.jsonl
```

`--out` 只在你明確要存權重檔時使用。

`node scripts/v2-learn-vs-hard.mjs` 用倉庫裡的驗證牌組、固定且分開的訓練／評估種子，做學習版對困難版，並附上相同牌組與種子的困難對困難基準。學習版會交換座位；跨作品時也會交換它拿的牌組。教師是合成規則，不是真人。對局不夠時結果標成探索性，不能把它說成已經證實強度提升。
