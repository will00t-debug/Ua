# V2 決策學習

這個程式讀取已經上傳的玩家決策，做出權重，供單人對戰的「學習」難度使用。

收集紀錄本身不會讓電腦變強。按下「用這些紀錄學習」之後，才有一個模型。模型猜中你的選擇，也不等於勝率已經提高。

## 學習用哪些列

- `source` 與 `actor` 都是 `human`。
- 當時有兩個以上合法選項。只有一個合法選項的步驟會略過。
- AI 操作、對局結果列、含對手隱藏手牌、牌序、未公開生命、種子或勝敗的列都會略過。
- 勝敗不會進特徵。
- 賽後示範若有修正，會當成額外的玩家選擇。沒有示範也可以學習。

特徵只用行動座位當時看得到的場面、資源、階段，以及這一筆合法操作的類型和公開卡號。

## 對戰時怎麼用

教 AI 頁的「用這些紀錄學習」會把權重存在這個帳號。有兩場以上時，會先留出最後一場計算猜中率，再把那一場也學進去。單人對戰把難度選成「學習」後，電腦在有把握時從合法操作裡選你以前會選的那一種；把握不夠，或這張卡你還沒選過，就沿用困難 AI `hard-search-2`。

權重留在帳號資料庫。不要把玩家匯出的 JSONL 或含真實對局的權重檔提交到 Git。

本機可以用：

```bash
node scripts/v2-decision-learn.mjs 匯出的.jsonl
```

`--out` 只在你明確要存權重檔時使用。
