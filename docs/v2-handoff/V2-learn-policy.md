# V2 決策學習

這個程式讀取已經上傳的玩家決策，做出權重，供單人對戰的「學習」難度使用。

收集紀錄本身不會讓電腦變強。按下「用這些紀錄學習」之後，才有一個模型。模型提出和你相同的選擇，也不等於勝率已經提高。

目前的模型格式是 `ua-v2-learn-v2`。`ua-v2-learn-v1` 不能套用新特徵，對戰時會沿用困難 AI，並提示重新學習。舊權重會留在帳號裡，未驗證的新結果不會覆蓋它。

## 學習用哪些列

- `source` 與 `actor` 都是 `human`。
- 當時有兩個以上合法選項。只有一個合法選項的步驟會略過。
- AI 操作、對局結果列、含對手隱藏手牌、牌序、未公開生命、種子或勝敗的列都會略過。
- 勝敗不會進特徵。
- 賽後示範若有修正，會和該場原本的決策留在同一邊。沒有示範也可以學習。

特徵是「當時看得到的場面」配上「這一筆合法操作」。生命、AP、能源、空位和阻擋人數會跟著攻擊、阻擋、放行、登場、突襲、移動或結束階段一起編碼。同一局面裡每個候選都一樣的數字，不會再單獨加分。

卡牌 UID 只用來找到這一手看得到的牌。跨對局學的是卡牌屬性、位置、目標和突襲底座；卡號只是補充。場外、除外和授權檢視區只使用引擎已經公開給該座位的牌。看不到的牌保持未知。

## 怎麼驗證

有兩場以上、而且留出後訓練側仍夠用時，會留出最後一場完整對局做獨立評估，再另外用全部可用決策訓練最終權重。對局不夠時會標明無法可靠驗證，不會把同一場切成兩半。

留出結果按攻擊、阻擋、登場、突襲、選牌等類型列出樣本、提出、相同和回退。提出選擇不等於改掉困難 AI。原始分數差不是機率，畫面上也不換成百分比。

合法操作超過 64 個時，負例用可重現的抽樣，不依按鈕順序取前幾個。

## 對戰時怎麼用

教 AI 頁的「用這些紀錄學習」會把權重存在這個帳號。單人對戰把難度選成「學習」後，困難 AI 先評分。學習偏好只在已經比較過的合法操作上，加減最多 18 分的有限權重。

立即斬殺、會立刻輸掉的操作、可見資訊下可證實的必要阻擋，以及能源很低時的補能源，仍沿用困難 AI。分數差不夠、樣本不足、沒看過的情境、舊模型或壞掉的模型，都回退困難 AI。回傳的操作必須是當下的合法操作。既有的階段步數上限仍然在。

診斷可以分出困難 AI 原選擇、學習偏好、最終選擇、有沒有真的改走法，以及回退或保護原因。診斷不寫進每一步的正式日誌。

權重留在帳號資料庫。不要把玩家匯出的 JSONL 或含真實對局的權重檔提交到 Git。

本機可以用：

```bash
node scripts/v2-decision-learn.mjs 匯出的.jsonl
```

`--out` 只在你明確要存權重檔時使用。

`node scripts/v2-learn-vs-hard.mjs` 用倉庫裡的驗證牌組、固定種子和引擎產生的合成偏好做學習版對困難版。那不是真人對局，不能把它說成已經證實能向玩家學習。
