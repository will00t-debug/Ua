# 美食獵人 UA17 共通引擎登錄

日文產品是 `UA17BT`（系列 `570117`）與 `UA17ST`（系列 `570017`），2024-02-23 發售。牌組編輯器的作品名用「美食獵人」。官方繁中產品頁寫的是「為食獵人」。繁中單卡頁目前仍是 coming-soon，所以 `name`、`effect` 保持日文官方印刷，不採用粉絲翻譯。

目錄有 109 個可組身份：補充包 `TRK-1-001` 到 `TRK-1-100`，以及只在起始牌組的 `TRK-1-101` 到 `TRK-1-109`。`TRK-1-041` 同時有補充包與起始牌組印刷，仍是一個身份。平行卡是另一個印刷，AP 卡不是牌組卡。

## 已接到共通引擎的整張印刷

`engineKind` 只有在整段日文（含觸發）對上共用程式時才寫入。新句子是加在共通引擎上的共用能力，不是美食獵人專用 opcode。編號身份 109 張，加上 3 張 `UAPR/TRK-P-` 點數交換角色，`createTrkV2Pack` 共 112 張。沒有 `trk` opcode，也沒有作品私有 runtime。

## 留在目錄、不進對戰包

編號目錄 109 張，以及 3 張點數交換角色，都已整段對上，沒有 `engineKind` 仍是 `null` 的身份。這不是 FAQ 全數認證。點數交換卡是牌組角色，不是行動值卡。官方單卡頁沒有這三張的 FAQ。

`TRK-1-005` 的發生能量圖檔是 `yellow2`，官方 alt 是 `黄+`，所以 `gen` 是 1、`genMark` 是 `+`，必要能量 `黄-` 是 0 且顏色仍是黃。047、082 是同一句的藍、紫印刷。

已經整段對上的顏色觸發、特徵檢索，以及「特殊觸發：退場 1 張對手前線」都在這 109 張裡。斜線特徵 `美食會／副料理長`、`美食會／ボス`、`美食會／料理長`、`美食會／料理人` 各是一個印刷特徵，沒有拆開。

## 這次避開的登錄錯誤

- 發生能量數 alt 裡的顏色點數。檔名裡的數字是圖檔編號。尾端 `+` 是 `genMark`，不加進 `gen`。必要能量的 `-` 是 0，顏色字元保留。
- `BP+` 是設計標記，整數才是基礎 BP。
- 一個卡號一個身份。平行卡不是新 id。AP 卡不進目錄。
- 只在整張日文對上共用程式時寫 `engineKind`。不把 `auto` 改成 true，也不做半張登錄。
- 看牌庫頂端時保留整窗 uid。進場仍走共用的選卡、再選格子；這批已登錄卡沒有進場句，所以沒有另做按鈕。
- 沒有把美食獵人加進五作品普查 `V2_TITLE_IDS`，也沒有加進舊的 `match-runtime.mjs`。作品登錄的 `playable` 是 false。
- 系列 FAQ 有掛到對應卡（例如 `TRK-1-002` 的 Q796）。這不是 FAQ 全數認證，`fullyAccepted` 維持 0。
- Wikimedia Commons 沒有這部作品的字標。標題選擇畫面改用目錄卡圖，沒有自造 logo。
