## 先前錯誤對照（本彈必須遵守）

- 發生能源只數 alt 色球；不要把 `ico_resource_energy_*N.png` 的 N 當成產能。
- 突襲框內效果只在正面向上的突襲狀態發動；框外句子在一般登場仍有效。見 `raid-box.mjs`。
- 牌庫頂檢索／查看必須保留整段視窗 UID（含不能選的卡）；不合格卡仍顯示但不能選。
- 效果讓角色進場走共用場地手勢（選卡 → 突襲／普通進場若印刷允許 → 點格子），不要為每個空格各做一個執行鍵；印刷沒寫的突襲／休息模式不要發明。
- 不要只翻自動支援旗標；不要半張卡登錄。

## 新接上的行為（封閉／條件）

- `alsoEventAura`：前線的〈マキマ〉（022／024）讓自己其他紫色角色在所有區域也視為事件。037 的其中一項是本回合授權。使用當下還不是事件的角色，之後被當成事件也不算「使用事件」（Q2079）；既有 `usedOwnEventThisTurn` 維持使用當下判定，CSM 連續層用 `csmEventUseCount`。
- 事件張數門檻：010（場上有マキマ時）依本回合已使用事件數疊 BP／不可被 BP4000 以上阻擋；015 每張已使用事件 BP+500。
- 〈デンジ〉退場窗口：016／027／029／031 等看「這個回合自己場上的デンジ有沒有真正退場」。
- 「場與場外 BP4000 以上的卡都是レゼ」：016／017 的條件把別名レゼ（含ボム）算進去（Q2077／Q2078）。
- 裏向底卡：047／048／051／054／056／061／067／075／076／077／078 等；控制者看得到，對手只看背面（系列 FAQ 多則）。
- 必擋授權：061 登場時若場上有デンジ，本回合可得到「對手必須阻擋」。
- 離場替代：061 的 BP500 以上退場可改退其他 BP4000 以上前線。
- 突襲框（`raid-box.mjs`）：017／023 `main`；048／066 `attackEnd`；056 `phase`+`onAttack`；061 `attackWin`+`leaveReplace`；066 另有 `phase`（エンド開始換位）。024 的前線光環與登場時不在框內。047 的【インパクト無効】用 `raidImpactNull`（只在正面向上突襲）。
- 021／057 的「看頂 N、1 枚まで場外、其餘回頂」走共用 `inspectTopAnyOutside`；053 的加手後棄牌由 `searchTopOneBottomDiscard` 預設處理。
- 早川 アキ：引擎名保留空白，另加別名 `早川アキ` 給檢索與突襲名。

已知缺口（不影響登錄）：部分裏向底卡／換位／056 細部在極端堆疊下仍可能需補 FAQ 鏈；全面官方 FAQ 認證仍是 0。
